# 红魔平板机型配置

## 目标与范围

用户要求将和平精英识别为红魔平板。最终采用 COPG v7.5.1 + Zygisk Next v1.5.1，并将配置限定到 `com.tencent.tmgp.pubgmhd`，使用红魔平板 NP05J 配置。

## 已验证

- COPG 和 Zygisk Next 均来自对应发布包，安装记录和版本信息保留在 `evidence/`。
- 运行时记录显示和平精英进程收到 NP05J 配置。
- 系统全局 model 仍是 `23046RP50C`；CPU 等真实硬件信息没有整体伪装。
- 全局附加开关关闭，配置只对游戏包生效。

## 边界

这是应用级属性配置，不是反作弊绕过。腾讯官方规则明确禁止 root 设备，root 和机型伪装可能带来账号、兼容性和封禁风险；本归档只记录配置是否按要求写入，不对游戏账号安全作保证。

## 恢复

`rollback/恢复和平精英原机型.ps1` 用于恢复原机型配置并重启相关模块。
