### HP/EP/LP 对比说明
- SCENE至多为同一处理器提供三种性能调节配置
- `HP` 提供更广泛的适配
  ```txt
  # 为主流高性能SOC提供专用配置
  # 为主流的低性能SOC提供兼容配置
  ```
- `EP` 配置适配 `性能&效率` 极佳的主流SOC
- `LP` 仅支持以下处理器，原则上不再增加新SOC
  ```txt
  mt6893 mt6895 mt6897 mt6983 mt6985 mt6989
  lahaina waipio cape ukee kalama pineapple sun canoe
  ```


#### HP
- HP是`high performance`的缩写，目标是：

  ```txt
  综合考虑处理器能效和性能需求，注重能耗/体验的平衡
  ```

- 具体做法为：

  > 在一般应用中
  ```txt
  # 适当限制CPU峰值频率
  # 使用`辅助调速器`减少CPU高频使用
  # 无操作时，更严格的限制CPU升频积极性
    > 导致视频转码、解压缩等操作耗时增加
  ```

  > 在游戏中
  ```txt
  # 避免激进的升频，将处理器频率控制在能效更高的范围内
  # 在游戏中可选开启FAS，以更好的控制CPU频率
    > 开启FAS会丢失一些帧率，并可能降低操控响应速度！
  ```
  


#### EP
- EP是`extreme performance`的缩写，目标是：

  ```txt
  在不造成严重(功耗)浪费的前提下，尽可能的释放CPU性能
  ```

- 具体做法为：

  > 在一般应用中
  ```txt
  # 适当的提高大核使用积极性
  # 相对积极的提升CPU频率，设置更灵活的频率范围
  # 无操作时，适当降低CPU升频积极性
  ```

  > 在游戏中
  ```txt
  # 去除各种可能限制CPU升频的系统设定
  # 相对积极的提升CPU频率
  # 辅助提升DDR、L3频率
  ```



#### LP
- LP是`low-power`或`low performance`缩写，目标是：

  ```txt
  在能保障基本的流畅度前提下，尽可能的限制处理器频率
  ```

- 具体做法为：

  > 在一般应用中
  ```txt
  # 大幅降低CPU频率上限，控制峰值功耗
  # 使用`辅助调速器`减少CPU频率跳跃
  # 尤其是无操作时，将更长时间保持在较低频率
    > 导致视频转码、解压缩等操作耗时大幅增加
  # 部分处理器还会按需孤立部分核心，最大限度减少低负载功耗
    > 典型的低负载场景如：置播放音乐、视频、阅读小说
  # 在音乐、短视频、小说、新闻应用中静置时限制帧率
    > 通过限制静置帧率，可减少Gif、广告元素造成的耗电
  ```

  > 在游戏中
  ```txt
  # 默认为所有游戏启用FAS，更好的控制CPU频率
  # 会丢失一些帧率，并可能降低操控响应速度！
  ```
