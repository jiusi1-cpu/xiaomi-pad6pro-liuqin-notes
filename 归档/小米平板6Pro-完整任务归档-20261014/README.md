# 小米平板 6 Pro 完整任务归档

生成日期：2026-10-14  
设备：小米平板 6 Pro（`23046RP50C`，代号 `liuqin`）  
系统：HyperOS `OS3.0.7.0.VMYCNXM` / Android 15  
归档状态：本地完成，尚未绑定 GitHub 仓库。

## 这份归档包含什么

本包把此前已经执行过的刷机、KernelSU、MT/Scene、桌面启动、刷新率与后台限制、和平精英性能、红魔平板机型配置、皮肤资源导入等工作整理成主题文档，并附上可复核的证据、恢复脚本和已验证的本机模块。

`01` 至 `07` 是面向阅读和后续上传的主文档；`evidence/` 保存关键 JSON、日志和截图；`scripts/` 保存可复查或恢复用脚本；`modules/` 保存本机专用 `liuqin120` 模块。

## 当前结果速览

- 官方完整系统镜像已从设备当前系统分区提取并完成校验，系统已干净重装；用户授权清空数据。
- 官方 KernelSU v3.3.1 build 32680 的 LKM 版本已写入并在正常启动中验证 root。
- MT 管理器 2.26.10、Scene 9.4.11 已安装并验证 root。
- 桌面与应用启动做了 ART speed 预编译；动画时长回到原厂默认值 1.0。重复“打开应用 → 底部上滑回桌面 → 立即重开”测试已完成，首次冷启动仍可能有初始化长帧。
- 全局原生显示模式已在重启后验证为 120Hz；`liuqin120` 模块和 23 个选定应用的后台限制已验证持久生效。
- 和平精英训练场最后一轮有效采样平均 118.37 FPS，10 秒窗口为 114.7–120.0 FPS；存在少量长帧，因此不能写成“任何场景绝对锁 120”。
- 红魔平板 NP05J 配置只对和平精英包名生效，系统全局机型仍保持小米原机型；未实施反作弊绕过。
- 当前新皮肤 ZIP 内的 5 个文件已复制到游戏 Paks 目录并逐个 SHA-256 校验；设备随后断开，外观是否在游戏中显示没有完成目视确认。旧的 0.27 资源已按用户要求删除，归档只保留其撤回记录。

## 上传 GitHub 前的处理

当前工作目录没有 Git 仓库和 remote。上传前需要在 GitHub 侧决定仓库地址和可见性。建议把本归档作为私有仓库材料；系统镜像、KernelSU/应用 APK、第三方皮肤资源、设备序列号和原始调试日志不适合直接公开分发。

本目录只收录了可复核的摘要和精选证据。完整系统分区镜像、7 GB 级别的 OTA 临时包等大文件仍留在本机原目录，并在 `raw-materials-manifest.json` 中列出路径、大小和 SHA-256，没有重复塞进适合 GitHub 的主压缩包。
