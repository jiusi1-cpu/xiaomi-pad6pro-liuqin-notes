# 和平精英：120Hz、后台限制与实际帧率

## 已应用并验证

- `liuqin120` v1.2（versionCode 3）KernelSU 模块已启用；完整重启后 SurfaceFlinger 和系统设置均为原生 120Hz。
- 23 个选定应用设置了后台活动、UID 级后台和自启动限制，重启后逐项核对通过。
- 桌面、系统服务、网络、游戏和 Scene 的必要权限保留；`com.miui.huanji` 与 `com.miui.backup` 共用 UID 6100，已排除并恢复权限。
- 和平精英使用流畅画质和 120 帧档位，抗锯齿关闭并保存。
- 采集到的主线程、渲染线程和 RHI 线程使用了 4–6 等允许范围；没有把整个游戏强行锁到单一 CPU 核。
- GPU 仍按负载调频，读取到的最大频率 900 MHz；没有添加 GPU 超频或 GPU 核心绑定。

## 最后一轮有效实测

训练场采样有效帧时间跨度 87.48 秒，共 10356 个呈现帧：

| 指标 | 结果 |
| --- | ---: |
| 平均帧率 | 118.37 FPS |
| 10 秒窗口 | 114.7–120.0 FPS |
| 帧间隔中位数 | 8.33 ms |
| 95% 帧间隔 | 8.39 ms |
| 99% 帧间隔 | 16.66 ms |
| 超过 16.7 ms | 15 次 |
| 超过 25 ms | 1 次 |

这证明显示链路和游戏设置已经能稳定进入 120 帧档位附近，但没有证明完整对局、所有地图和所有温度条件下绝对保持 120 FPS。系统 120Hz 也不会自动把应用自身的 60 FPS 上限变成 120 FPS。

## 参考方案

- XGMRXXC/RefreshRateSwitcher：参考其 Xiaomi 刷新率控制和 KSU 模块结构；本机固定 120Hz 不需要额外常驻守护。
- Neostein65/Force-120Hz-on-All-Apps-HyperOS-3-ADB：说明 HyperOS 刷新率设置路径；作者设备不是本机，已通过本机重启实测补足。
- KernelSU 官方模块机制：用于开机完成后恢复本机显示与后台限制。

## 恢复

`rollback/恢复全局刷新率与后台限制.ps1` 会停用本机模块、恢复此前显示与后台权限并重启。该脚本保留 KernelSU、Scene 和红魔平板配置。
